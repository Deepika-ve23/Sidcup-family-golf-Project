🌐 Sidcup Family Golf - Interactive Website Clone
📌 Project Overview

This project is a modern, interactive website clone of Sidcup Family Golf. It is built using HTML, CSS, and JavaScript, focusing on smooth animations, engaging UI, and immersive user experience.

The website showcases a golf facility with sections like services, about, testimonials, and interactive cards.

🚀 Features

✨ Custom Cursor Effect

Interactive cursor with blur effect that follows mouse movement

🎥 Video Background

Fullscreen autoplay background video for a premium feel

🧭 Sticky Navigation Bar

Animated navbar that changes style on scroll using GSAP

🎯 Scroll Animations (GSAP + ScrollTrigger)

Smooth animations for:
About section
Cards
Text elements
Page transitions

🃏 Interactive Cards

Hover effects with overlay content and 3D rotation

📜 Infinite Scrolling Text

Animated marquee-style scrolling section

🎨 Modern UI Design

Clean layout with responsive styling
Gradient sections and hover effects
